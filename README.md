# testrobbit

Python fanidan onlayn test topshirish tizimi.

## Imkoniyatlari:
- Foydalanuvchi ism va familiyasini kiritib kirishi
- 20 ta Python savollari (String, Arifmetik amallar, Boolean, if-elif-else)
- Savollar va variantlarning har safar tasodifiy (random) tartibda almashib tushishi
- Natijalar ko'rinishi:
  - To'g'ri ishlangan savollar soni va foiz
  - Mezon ranglari: Yashil (Yaxshi, 70%+), Sariq (O'rtacha, 50-69%), Qizil (Yomon, <50%)
  - Xatolarni to'liq ko'rib chiqish imkoniyati
